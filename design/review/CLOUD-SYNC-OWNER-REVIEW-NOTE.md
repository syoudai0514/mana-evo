# Cloud Sync Owner Review Note

Before merge, show the owner the following summary:

**これまで:** 端末保存は即時だが、クラウド同期は最後の変更から1.4秒後で、連続操作やプロフィール切替直前にクラウド到達が遅れる余地があった。

**変更後:** 端末保存は即時のまま。クラウドは0.8秒debounce、連続操作でも最大4秒で一度同期を試す。復帰・再接続・バックグラウンド化・プロフィール切替で即時reconcile。プロフィール切替は現在プロフィールを同期してからactive profileを変更する。同期要求は直列化し、競合writeを起こさない。

**理由:** 端末紛失・Safari終了・通信断・複数端末利用でも、子どもの進捗を失う可能性を下げるため。

**子どもへの影響:** 通常操作はクラウド待ちで止めない。通信がなくても端末に保存して続けられる。

**守ること:** 同一プロフィールの二重変更を自動上書きしない。別プロフィールなら安全に統合。TESTを本物セーブへ混ぜない。古い同期完了で新しいローカル変更を同期済み扱いしない。
