# 野生の出現と捕獲の設計

> 捕獲の数式・演出・野生出現テーブル・rank軸・エンカウント固定ルールの正本。
> `01-catch-and-evolution-design.md` と `06-battle-and-progression-design.md` は本書を参照する。

## 0. 要約

| 項目 | 決定 |
|---|---|
| 捕獲方式 | **方式Aに一本化**（勝利→捕獲フェーズ→わ→最大3投）。HP残量・状態異常による補正は無し |
| 捕獲式 | `P = (a/255)^(3/4)`、`a = min(255, rate × ball倍率)`。HP項は使わない |
| 「かならずつかまる」表現 | **にじのわ 以外には使わない**（3投累積でも100%にはならない） |
| rankの役割 | **捕獲のしにくさだけ**を表す軸。野生に出るか／進化専用か／一回限定かは別軸で判定 |
| 一回限定遭遇 | 単体系列5体のみ（rank=legendの13体全部ではない） |
| 野生出現プール | legend rank は含まない（進化専用・一回限定のどちらかであるため） |
| 未捕獲補正 | 未登録種は出現重み×1.5、3匹以上捕獲済みの種は×0.6 |
| エンカウント固定 | 遭遇は **RESOLVED になるまで同じ encounterId を保持**。逃走・敗北・画面離脱では再抽選されない |

## 1. 捕獲の数式（方式Aのみ）

```
a = min(255, rate × ball倍率)
P（1投） = (a / 255)^(3/4)
P（3投累積） = 1 − (1 − P)^3
```

この簡約形は、参考にした旧来式の4段階サブ判定と同じ最終成功確率になる
（a = 10/45/90/135/180/200/254 の7点で元式と検算済み）。**ここで述べているのは確率計算の由来のみで、視覚演出の仕様ではない。**

旧方式Bで使っていたHP残量の補正項
（`(3×HPmax − 2×HPcur) / (3×HPmax)`）は「戦闘中に捕獲する」方式用であり、本作では使わない。
方式Aでは捕獲フェーズに入る時点で敵は必ずHP0（たおしている）なので、HP項は意味を持たない。撤廃した。

| ランク | rate | ほしのわ×1 | ぎんのわ×1.5 | きんのわ×2 | にじのわ |
|---|---|---|---|---|---|
| ふつう | 200 | 1投83% | 1投100% | 1投100% | 1投100% |
| めずらしい | 90 | 1投46% | 1投62% | 1投77% | 1投100% |
| とてもめずらしい | 45 | 1投27% | 1投37% | 1投46% | 1投100% |
| でんせつ | 12 | 1投10% | 1投14% | 1投17% | 1投100% |

### 3投累積（誇張表現の禁止）

> ふつう×ほしのわでも厳密な100%ではない。
> 1投成功率は83.34%、3投累積は**約99.54%**。したがって「かならず」と表示しない。

| ランク | ほしのわ 3投累積 | ぎんのわ 3投累積 | きんのわ 3投累積 | にじのわ |
|---|---|---|---|---|
| ふつう | 99.54% | 100.00% | 100.00% | 100.00% |
| めずらしい | 84.07% | 94.54% | 98.78% | 100.00% |
| とてもめずらしい | 61.46% | 74.88% | 84.07% | 100.00% |
| でんせつ | 27.35% | 35.71% | 42.81% | 100.00% |

**「かならずつかまる」「100%」と言えるのは にじのわ だけ。** それ以外は画面でも
「ほとんど つかまる」「つかまえやすい」「つかまえにくい」のような相対表現にとどめ、
数字を見せる場合も小数点まで正直に出す（丸めて100%と表示しない）。

### 表示ラベル（UIでの見せ方）

| 3投累積 | 表示 | ★の目安 |
|---|---|---|
| 99% | ほとんど つかまる | ★★★★★ |
| 85% | つかまえやすい | ★★★★☆ |
| 60% | ふつう | ★★★☆☆ |
| 30% | つかまえにくい | ★★☆☆☆ |
| 10% | かなり つかまえにくい | ★☆☆☆☆ |

### 視覚演出（確率計算とは分離）

- 画面上の主役は**4つの星が順に点灯して輪が完成する**こと。
- 成功時は4つ点灯後に輪が虹色に閉じる。
- 失敗時は途中まで点灯した星が散り、輪がほどける。
- 「わ」が4回物理的に揺れることは必須仕様にしない。
- 内部で段階的なサブ判定を用いる場合でも、それをそのまま物理アニメーション回数へ結びつけない。
- UI詳細は `03-screens-catch-and-raise.md`、横断原則は `08-gameplay-state-spec.md` §10 を優先する。

## 2. 捕獲の救済は入れない

「3回逃げられたら次は必ず成功」のような隠し救済は入れない。
低確率で3投とも失敗すること自体は、

- 「次はきんのわを使おう」
- 「にじのわ はこの子まで取っておこう」
- 「もう少し勉強してわ を増やそう」

という動機になるため、価値として残す。ここを甘くすると、わ を選ぶ意味そのものが薄れる。

## 3. rank・野生出現・一回限定を別の軸にする

rank=legend（13体）には、通常の3段階系列の最終進化形
（進化すれば何度でも入手できる）が9体含まれるため、「legend=固定の1回きり」と
説明しない。

rank は **捕獲のしにくさだけ**の軸として使い、以下は系列の形から別に判定する。

| 軸 | 値 | 判定方法 |
|---|---|---|
| rank | ふつう／めずらしい／とてもめずらしい／でんせつ | データで直接指定（捕獲式の rate に使う） |
| pool（出会い方） | wild／evolutionOnly／event | 系列内の位置（第1〜中間形態＝wild／最終形態＝evolutionOnly／単体系列＝event）から自動判定 |
| repeat（何度でも入手できるか） | unlimited／once | pool=event（単体系列）だけが once |
| bossGated | true／false | pool=event（単体系列）だけが true |

実データでの内訳: wild 155体 / evolutionOnly 79体 / event 5体

rank=legend（13体）のうち、実際に一回限定なのは 4体だけ。
残り9体（コスモドラグ、アストラーゼ、イグナヴェル、ヨルシジマ、ステラリーゼ、フェニクロス、オケアノス、テンライガ、アマツクジラ）は、進化すれば何度でも入手できる
（evolutionOnly＝最終形態のため野生には出ないが、捕獲→育成→進化で誰でも到達できる）。

この分離により、「legend=激レア」という直感は保ったまま、
「でも進化で手に入る子はちゃんと手に入る」を両立できる。

## 4. 野生出現テーブル

### 出現の重み（rankベース）

| rank | 重み |
|---|---|
| ふつう | 60 |
| めずらしい | 30 |
| とてもめずらしい | 9 |
| でんせつ | （野生プールに含まれない。§3参照） |

エリア内の「wild」個体（＝非最終形態）を対象に、上の重みで抽選する。
同じエリア内でも、ふつうランクが圧倒的に出やすく、とてもめずらしいはごくまれ、という体感になる。

### 未捕獲補正・連続抑制

| ルール | 値 |
|---|---|
| 未登録種の重みボーナス | ×1.5 |
| 3匹以上捕獲済みの種の重みペナルティ | ×0.6（0にはしない＝厳選目的の再訪も許す） |
| 直前と同じ種の連続出現 | 次の1回だけ出現プールから除外 |

図鑑を埋めたい子には自然と未登録種が多く出て、埋まった後は「同じ子ばかり」になりにくい。

### エンカウント固定ルール（不正対策の核心）

> **何が問題だったか。** 「負けてもチケット消費なし」×「敗北すると敵が再抽選される」の組み合わせは、
> 「レアが出るまでわざと負ける／わざと逃げる」を許してしまう抜け道になる。

遭遇した個体は、以下のいずれかまで**固定**する。

| できごと | 次の遭遇 |
|---|---|
| 敵HPを0にして「たおした！」 | **同じ encounterId の捕獲フェーズへ**。捕獲成功/3投失敗でRESOLVED後、次回だけ新しい抽選 |
| 3投とも失敗して「にげられた」 | 新しい抽選 |
| 全滅してHP全快した | **同じ相手のまま**（再抽選されない） |
| 「にげる」を選んで戦わずに離脱 | **同じ相手のまま**（再抽選されない） |

**結果として**: わざと負けても同じ相手と戦い直すだけで得しない。
「にげる」を選んでも同じ相手が残るため、レア厳選の近道にはならない。
隠しペナルティを追加せず、**構造だけで抜け道を塞ぐ**方針にした。

## 5. ボス・イベント遭遇

| 種別 | 対象 | 遭遇条件 | 捕獲 |
|---|---|---|---|
| エリアボス | 各エリア1体（4体） | 学習進行12pt かつ異なるskill 2つ以上（詳細は `08-gameplay-state-spec.md` / `AREA_BOSS_UNLOCK`） | 倒すと物語イベントとして仲間になる（捕獲判定なし） |
| 単体系列（5体） | ユグドラシア・ホシラディア・ガイオドール・メテオルド・シラユキヒメ | 物語の節目で1回だけ遭遇 | 専用の捕獲演出（にじのわ相当の確定入手、または専用イベント） |

単体系列はそもそも「野生で何度も出る」対象ではないため、通常の出現テーブル（§4）には含めない。
