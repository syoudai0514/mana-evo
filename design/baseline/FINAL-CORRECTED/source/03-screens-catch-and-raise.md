新ゲームの画面案8枚。すべて **iPhone縦 375×667px** で実測し、はみ出しがないことを確認済み。

## 1日のループ

```
勉強する → 「わ」をもらう → バトルに勝つ → どの わ を投げるか自分で決める → つかまる／逃げられる
   ①            ①                             ②                    ③              ④
```

前作との決定的な違いは、**勝っても必ず手に入るわけではない**こと。だから「どの わ を使うか」が5歳にとって最初の本物の選択になります。
勝利＝バトルの権利（チケット）、捕獲＝わ、と役割が分かれているので、勝利した戦闘はチケットを1枚消費し、捕獲失敗でも返却されません。

## 画面1: 学習クリア → わ をもらう

学習とゲームの因果を、この画面ひとつで見せます。

**構成（上から）**
1. 「こくご クリア！」（29px / weight 900）＋「5もん ちゅう 5もん せいかい」
2. **わ の獲得行**（2つ）
   - ⭕ **ほしのわ +1** — 「タスクを 1つ クリア」（ミント枠）
   - ⭕ **ぎんのわ +1** — 「きょうの こうろを ぜんぶ クリア！」（シルバー枠）
3. **レベルアップ通知**（ゴールド枠・3px）。**進化条件を越えたかどうかで、この先が分岐する**（`01-catch-and-evolution-design.md` §5「進化が発生するタイミング」に対応）
   - **越えていない場合**: モンスター絵 70px ＋「ヌリン が レベルアップ！」「Lv.15 → Lv.16」＋「しんかまで あと 4レベル」
   - **越えた場合**: **その場で進化演出へ遷移する**（「つぎのバトルで」と先送りにしない）。学習画面の中で
     「ヌリン が しんかした！」まで一気に見せる。**「勉強したから進化した！」の因果をこの1画面で完結させる**
4. **もっている わ**（4種の数を横並び）: ほし12 / ぎん4 / きん2 / にじ1
5. ボタン2つ: 「⚔️ さがしに いく」（ピンク）「つぎへ すすむ」（ミント）

**要点**: わ のアイコンはSVGで描く（絵文字では「輪」に見えない）。星→銀→金→虹 で色が強さの順になっている。
進化演出では、進化後の姿とステータス上昇を同じ結果画面で見せ、「学習→成長→進化」の因果を切らない。

## 画面2: かった → どの わ を なげる？

捕獲の中心。5歳にとって最初の本物の選択。

**構成**
1. 「たおした！」（25px・ゴールド）＋「どの わ を なげる？」
2. 相手のモンスター 112px ＋ 名前 ＋ Lv チップ
3. **つかまえやすさ ★★☆☆☆**（黒帯のピル内）— 捕獲難度を★と日本語ラベルで事前表示
4. **わ の2×2グリッド**（各 min-height 88px）
   - 各セルに：SVGの わ ／ 名前 ／ **★評価＋日本語ラベル**（%は詳細の小表示） ／ 右上に所持数バッジ
   - おすすめの1つはゴールド枠3pxで強調（例: きんのわ ★★★★☆「おすすめ！」）
   - 所持0のものは opacity 0.38
5. 「なげられるのは あと **3かい**」
6. 「なげないで もどる」

**要点**: 子ども向け主表示は **★＋日本語ラベル**。%は詳細表示または保護者向けの補助値に限定し、主ボタン・主情報にしない。読めない子でも星・色・強調枠で判断できるようにする。

## 画面3: 4つの星が光る → 輪が完成する

マナエボ独自の捕獲演出。**画面上の主役は「わの物理的な揺れ」ではなく、4つの星が順に点灯して輪が完成すること**。内部確率計算 `P = (a/255)^(3/4)` と視覚演出を分離し、内部実装で段階的なサブ判定を使っても、4回の物理的な揺れを必須にしない。

**構成**
1. 「きんのわを なげた！」（22px・ゴールド）
2. **中央に大きな わ（170px）**。モンスターのシルエットを包み、やわらかなグローを出す
3. **わ の円周に沿って星が4つ**。演出進行に合わせて時計回りに1つずつ点灯する
   - ★ ○ ○ ○
   - ★ ★ ○ ○
   - ★ ★ ★ ○
   - ★ ★ ★ ★ → 輪が完成
4. 「ほしが ひかっていく…」（27px）。星の点灯に合わせて輪の光が強くなる。**わの物理的な揺れ回数は仕様化しない**
5. 成功時: 4つ点灯した瞬間に**輪が虹色に閉じる** → 「ゲット！」
6. 失敗時: 途中まで点灯した**星が外側へ散り**、輪がほどけてモンスターが戻る
7. 下部の説明: 「ほしが 4つ ひかったら ゲット！ しっぱいしても あと 2かい なげられる。」

**要点**: 確率計算は `P = (a/255)^(3/4)` を変更しない。4つの星は成功/失敗を子どもに理解させるための独自視覚表現であり、確率式の内部由来をそのまま物理的な揺れとして再現する必要はない。

## 画面4: つかまえた → 図鑑とボックスへ

**構成**
1. 光条アニメーション（6本、放射状）
2. 「つかまえた！」（31px・ゴールド・影付き）
3. モンスター 152px（ゴールドのグロー）＋ 名前 25px
4. **3行の記録**
   - 📖 ずかんに **とうろく** したよ — 右に `No.038`
   - ⭕ **きんのわ** で つかまえた — 右に「2かいめ」
   - 📦 ボックスに はいったよ — 右に「14ひきめ」
5. **進化の予告**（ミントの帯・つかまえた直後に必ず出す）
   - > **「この子は 2かい しんかするよ！」**
   - > 「つぎの すがたまで あと 15レベル」
6. ボタン: 「✏️ なまえを つける」「やったー！」（ミント）

**要点**: 図鑑（種族）とボックス（個体）の両方に入ったことを、その場で見せる。この2つが別物であることが自然に伝わる。
そして**捕まえた瞬間に「この子はもっと強くなる」を出す**。
つかまえる楽しみが、その場でそだてる楽しみに繋がる。

## 画面5: ずかん（しゅぞく 239枠）

種族のカタログ。「みていない／みつけた／つかまえた」の3状態を持ち、進化系列は1枚のカードで成長関係が分かるようにする。見た目・演出はマナエボ独自に統一する。

**構成**
1. ヘッダー: 🏠 / 「📖 ずかん」/ 「14/239」
2. **タブ**: 「つかまえた 14」「みつけた 6」「🔥」「💧」…（18タイプ分スクロール）
3. **系列カード**（縦積み）
   - 完成した系列: 3枠すべてミント枠 ＋「3 / 3 かんせい！」
   - **みつけた（影）**: 枠はゴールド、絵は `filter: brightness(0.12) contrast(2)` で真っ黒なシルエット ＋「にげられた／またあえるよ」
   - 未発見: 「？」
   - 進化条件を右端に表示（例: 「みずのいし で しんか」）
4. **ギガ／バースト対象の系列**には、最終形の枠に ✨ または 🌟 のバッジ
   - まだ解放していなければ「？」のタブ、解放後は「ギガの すがた」タブが開く

**要点**: 「みつけた（影）」があるから、逃げられても何かが残る。その悔しさが次に会ったときの動機になります。

## 画面6: ボックス（こたい・絞り込み）

捕まえた「個体」。同じ種族を何匹でも持てる。

**構成**
1. ヘッダー: 「📦 ボックス」/「21ひき」
2. **てもち 3/3**（上に固定）— 3列グリッド、出場中はミント枠
3. **絞り込みチップ**: 「✨ しんかできる 2」（ゴールド・選択中）「★ おきにいり」「レベルじゅん」
4. **個体グリッド**（4列）
   - 進化できる個体はゴールド枠3px ＋ 右上に ✨ バッジ
   - おきにいりは左上に ★
   - 同じ種族（テリン Lv.16 と テリン Lv.5）が並ぶ
5. **各個体のカード下端に、常に進化までの残りを出す**
   - 進化まであとレベルがある: 「しんかまで あと **6** レベル」＋ 進捗バー
   - 条件を満たした: 「**✨ しんかできる！**」（ゴールド・点滅）
   - いし待ち: 「みずのいし が あれば しんか」（持っていれば「つかう」ボタンが出る）
   - もちもの待ち: 「**きのよろい** を もたせて レベルアップ」
   - 最終形: 「さいごの すがた」＋ ギガ／バースト対象なら「✨ ギガコアで もっと つよくなる」
6. 下部: 「おなじ しゅるいでも 1ぴきずつ そだてられるよ」

**要点**: 「しんかできる」を絞り込みの先頭に置く。ここが子どもにとっていちばん押したいボタン。
そして**「あと何レベル」はどの画面でも常に見えている**ようにする。
ホームの相棒カード、バトル後のリザルト、ボックス、図鑑の4か所すべてに出す。
数えられる残り数があると、「もう1タスクやろう」が自分から出てくる。

## 画面8: とくべつな ちからを つかう子を えらぶ

> **仕様整合:**
> 旧版は「ダリンをギガシンカにする？キョダイバーストにする？」と**同じ1体について**
> 2択を選ばせる構成でしたが、データ上ギガ対象とバースト対象は**種族ごとに完全排他**
> （重複0）で、そもそも1体が両方を持つことはありません。矛盾していたのは画面の方でした。
> 正しくは、**パーティの中で誰の（すでに決まっている）切り札を使うか**を選ぶ画面です。

**構成**
1. 「とくべつな ちからが つかえる！」（22px・紫）＋「このバトルで つかえるのは １つだけ」
2. **手持ち3体のカード**（横並び。それぞれの子が持つ切り札は種族で固定・変更不可）
   - ダリン 56px ✨紫枠「ギガシンカ」チップ ＋ 「つかう」ボタン
   - センジュガ 56px 🌟金枠「キョダイバースト」チップ ＋ 「つかう」ボタン
   - モコハ（進化前） グレースケール・チップなし ＋「まだ とくべつな ちからは ない」
3. 「つかう」を押した子だけが変身する（**選択は1体まで**。2体目の「つかう」は押せない）
4. **選んだ子の詳細**（つかう を押すと展開）
   - ダリン → ▶ → **ギガダリン** 120px（紫グロー）／「ぜんぶの ちからが 1.35ばいに！／おわるまで ずっと」
   - センジュガ → ▶ → **キョダイバーストセンジュガ** 120px（金グロー・巨大化）／「たいりょく 2ばい・こうげき 1.2ばい／3ターンだけ」
5. **ルールの説明**（黒帯）
   - ⚠️ このバトルで つかえる とくべつな ちからは **1つだけ**。バトルが おわると もどるよ。
   - 💎 ダリンの ギガコア／センジュガの バーストのしるし を もっているから つかえる。
6. **まだ使えない子**（薄く表示）: 「ギガコアが ない」「まだ さいごの すがた じゃない」
7. 「いまは やめておく」

**ギガコア／バーストのしるしの入手が画面に出ている**こと: 「さいごの すがたに なると、○○の チャレンジが あらわれる」
——最終進化がゴールではなく、そこから次の目標が生えることを、この画面で見せる。

**要点**: 「この子はギガかバーストか」を選ばせない（種族で決まっているので選ぶ意味が無い）。
選ぶのは「今回の切り札を、どの子に使うか」だけ。使えない理由を明示するのが、次の目標になる。

**変身そのものが収集の報酬になる。** 図鑑登録まで含めて、特殊変身を育成後の次の目標にする。

| 0.00 | **足元から光の柱が立ち上がる**。カメラが下から見上げる角度へ | 地鳴り |

## 実装上の注意

1. **`box-sizing: border-box` を必ず入れる。** 内側の要素に `height: 100%` ＋ padding を同時に指定すると、padding分だけはみ出す。8枚とも最初これで56px溢れていた。
2. **375×667 で技ボタンが画面外に落ちないこと。** 変身・交代などのボタンを技グリッドの上に積むと、iPhone SE/8 で攻撃ボタンが1つも見えなくなる。技を先に並べ、ユーティリティは下に置く。
3. **ダイアログには `env(safe-area-inset-bottom)` を入れる。** `padding: 12px 12px max(12px, env(safe-area-inset-bottom))`。
4. **画像は実在するIDだけ参照する。** 未生成の絵を無条件に参照すると404が量産される。
