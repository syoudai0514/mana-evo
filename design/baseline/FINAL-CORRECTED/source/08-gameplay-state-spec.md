# ゲーム状態・報酬・地域進行の実装正本

> バトルチケット、遭遇状態、地域解放、学習報酬、探索、特殊変身HP、重複捕獲の横断仕様を固定する。詳細値の機械可読正本は `scripts/rewards.mjs` / `scripts/battle.mjs` / `scripts/wildEncounter.mjs`。下位文書と矛盾する場合はこの文書を優先する。

## 1. バトルチケットと遭遇の状態遷移

状態は `ENCOUNTERED → BATTLING → WON → CAPTURE → RESOLVED` を正本とする。

- バトル開始条件は **チケット残数1枚以上**。開始時は残数を減らさず、同一遭遇への再挑戦用に `encounterId` を保持する。
- **勝利確定時にチケットを1枚消費する。** XP付与より先に `ticketConsumed=true` を永続化する。同一勝利の再読込で二重消費しない。
- 捕獲成功・失敗でチケットを追加消費/返却しない。
- 敗北はチケット非消費。同じ `encounterId` を保持し、HP全快後に同じ敵へ再挑戦する。
- 「にげる」もチケット非消費だが、同じ `encounterId` を保持する。別の敵は引き直せない。
- アプリ終了・戻る・誤タップで画面離脱しても `encounterId` を保存する。
- 新しい野生抽選は、勝利後の捕獲フェーズが成功/3投失敗で解決した後だけ行う。
- 勝利→保存前クラッシュの二重消費を防ぐため、`battleResolutionId` を冪等キーにする。
- チケットは**獲得日ごとに7日間保持**し、日付変更だけでは消えない。各ロットに `earnedAt` / `expiresAt`（または同等情報）を持つ。
- 消費は**期限が近いロットから**（FEFO）。期限切れロットは使用不可として整理する。
- 旧セーブが単純なチケット個数しか持たない場合も、移行時に個数を失わない。初回migration時点から7日有効の互換ロットへ一度だけ変換し、同じmigrationを再実行しても重複付与しない。

これにより「勝利XPだけ獲得して捕獲失敗でチケットを返してもらう」「逃げ続けて無料厳選」はできない。

## 2. 地域解放

### 用語

- `area` = アセット制作・データ分類上の単位。
- `adventureRegion` = プレイヤーが移動・探索するゲーム内地域。
- 地域解放判定は `adventureRegion` に対して行い、制作上の `area` と同一視しない。
- コンプ率ではロックしないが、地域2〜4は直前地域ボス初回撃破で順次解放する。未解放地域の野生・探索・アイテムテーブルにはアクセス不可。過去地域にはいつでも戻れる。


「制作上のarea」と「ゲーム内の地域解放」を分離する。コンプ率ではロックしない。

| 地域 | 解放条件 | 子ども向け表示 |
|---|---|---|
| 地域1 | 最初から | さいしょの ちいき |
| 地域2 | 地域1ボス初回撃破 | ボスに かった！ つぎの ちいきへ！ |
| 地域3 | 地域2ボス初回撃破 | 同上 |
| 地域4 | 地域3ボス初回撃破 | 同上 |

ボス挑戦に「全種類捕獲」「図鑑100%」「全科目クリア」は要求しない。ボス挑戦条件の正本は `scripts/rewards.mjs` の `AREA_BOSS_UNLOCK`。

- 地域ごとに **学習進行ポイント12** でボス挑戦候補になる。
- ただし **異なるskillを2つ以上** 進めていることも必要（科目は同じでもよい）。
- その日のコアタスク初回クリア `+1`、習熟度の段階上昇 `+2`、章末テスト初回合格 `+3`。
- 同じ設問の反復、すでに習熟済みの低難度問題の反復は `+0`。
- 判定式: `progressPoints >= 12 && uniqueSkillCount >= 2`。
- **`progressPoints` と `uniqueSkill` 集合は地域別に保持する。** 地域2〜4が解放された瞬間、その新地域は `0pt / skill空集合` から開始し、前地域で稼いだ値を持ち越さない。
- セーブ形式は例として `areaBossProgress[areaId] = { points, uniqueSkillIds[] }`。地域を戻って学習した場合は、その地域の値だけ更新する。
- 得意科目を深掘りしても解放できるが、簡単な同一問題だけの周回では解放できない。
- 地域2以降そのものの解放は直前地域ボス初回撃破。後半地域の探索テーブルは地域解放前には参照できない。

## 3. 学習報酬と連打対策

- 基本ノルマ達成で **バトルチケット+3** を維持。
- 追加問題1問クリアごとに **追加チケット+1、上限なし** を維持。
- きんのわは追加1問ごとには出さない。**追加4問セット中3問以上正解で+1**。
- 同一skillを続けてもよいが、習熟度85%以上では次の難易度へ上げる。得意を伸ばせる一方、簡単問題固定周回を最適化しない。

不正/連打判定は「900ms未満」や「同じ選択肢3連続」を単独理由にしない。直近8問について、異常な高速率・誤答率・同一問題反復・選択肢偏重・高難度なのに異常高速、の**2シグナル以上**で「疑わしい」とする。

疑わしくても学習XPは100%付与する。追加チケット/きんのわだけ一時保留し、正常回答3問で自動解除する。画面には理由と解除条件を表示する。

## 4. まもる

- 成功率100%、ダメージ/状態異常100%防御。
- **使った次の1ターンは使用不可**。PP・ランダム失敗は使わない。
- 使用直後に「つぎは まもるを つかえないよ！」を表示。
- ボス大技予告時は、まもる・こうたい・攻撃で押し切る、の3つが成立する。

## 5. 進化アイテム探索

学習と進化を直接接続する。

- コア全達成: たんけんポイント+2。
- 追加問題1問: +1。習熟度アップ: +2。章末テスト: +5。
- **5ポイントで探索1回**。1日回数上限なし。
- 探索先は解放済み地域のみ。地域ごとの進化アイテム表から抽選。
- 1回の探索は必ず何かを持ち帰る。通常素材80%、進化アイテム20%を基準値とする。
- **地域ごとに進化アイテムが5回連続で出なかった場合、6回目の探索開始時にその地域の進化アイテムを1個選べる。**
- 「目的アイテム」の事前登録状態は持たない。保存するのは `explorationPityMissesByArea[areaId]`（0〜5）だけ。
- 通常抽選で進化アイテムを1個得た時、または6回目の保証で1個選んだ時、その地域のカウンタを0へ戻す。通常素材なら+1。
- カウンタは地域別で、セーブ/ロード後も保持する。他地域の探索では増減しない。
- 重複アイテムは在庫に積む。進化で消費する通常アイテムであり、チケットとは別経済。
- ボス初回撃破の地域アイテム1個ボーナスは継続する。

子どもには「あと 2ポイントで たんけん！」「あと 1かいで ほしい しんかアイテムを えらべる！」と見せる。

## 6. わ の経済

ほしのわ=コアタスク、ぎんのわ=基本ノルマ達成、きんのわ=追加4問セット3正解、にじのわ=章末/ボス。わ は無期限保存。追加チケット無制限方針は変更しない。

## 7. 進化アイテムの表示時系列

「進化した直後に、進化条件だったアイテムを手に入れた」とは表示しない。

- アイテム入手時: 「○○を みつけた！ このこに つかえるよ！」
- 使用前: 「○○の ちからで しんかできるよ！」
- 使用後: 「○○を つかって しんかした！」

## 8. ギガシンカ/キョダイバーストのHP

### ギガシンカ
最大HPも含む全ステータス×1.35。現在HPはHP割合維持で変換する。例 `50/100 → 68/135`（四捨五入）。解除時も割合維持で通常最大HPへ戻す。

### キョダイバースト
発動時 `50/100 → 100/200`。3ターン終了時に `current/transformedMax` の割合を通常最大HPへ戻す。例 `74/200 → 37/100`。**0HPは0HPのまま**で最低1HP保証はしないため、瀕死回避ボタンにはならない。

## 9. 同種複数捕獲

複雑な個体値は導入しない。同じ種を捕まえたときは捕獲後に2択を出す。

- **なかまにする**: 別個体としてボックスへ。ニックネーム、捕獲日、使ったわ、覚えさせた技、育成レベルが個体の思い出になる。
- **おうえんにかえる**: `そだちのかけら` +1 に変換。**かけら3個で任意の手持ち1体へ育成XP +30**。正本は `GROWTH_SHARD`。標準学習は1日350XP（手持ち3体へ同額）なので、重複捕獲3回=30XPは補助報酬に留まり、捕獲周回を主要育成手段にしない。

初回捕獲は自動で「なかまにする」。2匹目以降だけ選択を出す。

## 10. 捕獲UI・演出

捕獲は「4回揺れる」を主役にしない。マナエボ独自の**4つの星が順に点灯して輪が完成する演出**を正本とする。成功時は輪が虹色に閉じ、失敗時は途中の星が散る。

5歳向け主表示は `★★★★★ / おすすめ！ / かなり つかまえやすい`。%は保護者/詳細表示の補助値とし、主ボタンには置かない。

## 11. シミュレーションの扱い

旧「約440日」は確定値ではなく、**基準ケース**と明記する。今後は少なくとも次の3ケースを出す。

- 標準: 毎日標準学習、遭遇/探索中央値。
- やや不運: 捕獲失敗・目的種待ち・探索天井を一部踏む。
- 高学習: 追加問題を多く解き、追加チケット/探索回数が増える。

表示指標は初進化、2段階進化、特別進化、図鑑100/300/全体相当、学習量と進行の相関。単純なジョブスケジューリング値を「完成日」と断定しない。

## 12. 旧仕様の扱い

過去版の設計や削除済み文書を実装根拠に使わない。このTerra用ZIPに含まれる正本と `scripts/` の現行値だけを参照する。ManaEvo側に旧仕様コメントや旧画面が存在する場合は、この正本へ合わせる。Kids Quest側は学習基盤のread-only参照元であり、このゲーム仕様へ合わせるための変更は行わない。
