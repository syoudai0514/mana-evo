## 1. ステータス

### なぜ4つだけにしたか

マナエボでは、5〜8歳が覚える数を増やしすぎないため、とくこう／とくぼうを分けない。
理由は「5歳が画面を見て、なぜ効いたのかを自分で説明できる」ことを守りたいから。
わざが物理か特殊かを覚えるより、**タイプ相性を考えることに脳を使ってほしい**。
タイプ相性を考える部分を、バトルの中心的な面白さとして残す。

| ステータス | 画面の呼び方 | はたらき |
|---|---|---|
| HP | **たいりょく** | 0になると たおれる |
| ATK | **こうげき** | あたえるダメージ |
| DEF | **ぼうぎょ** | うけるダメージを へらす |
| SPD | **すばやさ** | 高いほうが先に動く。同値なら乱数 |

### 種族値の決め方

種族値の合計（BST）は、**そのモンスターが系列内で「第1形態」「中間形態（3段階のみ）」「最終形態」の
どれに当たるか**で決まる。

> **何が問題だったか。** 旧実装は BST を「そのステージ番号」でそのまま引いていた
> （1段目=200 / 2段目=270 / 3段目=340）。すると **2段階系列の最終形が「2段目」＝270** になり、
> 3段階系列の最終形340と大差が付いた。**2段階系列は「最終形なのに中間形相当」の弱さになっていた。**
> ステージ番号ではなく「最終形かどうか」で決め直したことで、2段階でも3段階でも最終形は同じ340になる。

| 位置づけ | 基準BST |
|---|---|
| 第1形態（2段階・3段階とも） | 200 |
| 中間形態（3段階のみ） | 270 |
| **最終形態（2段階・3段階とも）** | **340** |
| 単体（進化なし） | 380 |

| ランク | 倍率 |
|---|---|
| ふつう | ×0.95 |
| めずらしい | ×1.00 |
| とてもめずらしい | ×1.08 |
| でんせつ | ×1.20 |

合計をロールで配る。**ロールは飾りではなく、この配分そのもの**。

| ロール | HP | こうげき | ぼうぎょ | すばやさ | 役目 |
|---|---|---|---|---|---|
| アタッカー | 24% | 36% | 18% | 22% | とにかく殴る。打たれ弱い |
| ガード | 32% | 20% | 34% | 14% | 受けて耐える。倒しきれない |
| スピード | 22% | 28% | 16% | 34% | 先手を取る。紙 |
| ヒーラー | 30% | 18% | 28% | 24% | 味方を回復する。攻撃は苦手 |
| サポート | 26% | 22% | 28% | 24% | 状態異常と補助。器用 |
| バランス | 26% | 26% | 24% | 24% | 穴がない。最初の相棒向き |

### 進化で1つもステータスが下がらない

> **何が問題だったか。** 155件の進化ステップのうち52件はロール（役割）も変わる
> （例: アタッカー→ガード）。BSTが増えていても、配分比率の変化幅の方が大きいと、
> 素の計算では一部ステータスが下がることがあった
> （例: ワカバネ→ジュランガ で こうげき 70→68、すばやさ 65→48）。

修正方針: 各ステータスを**「1つ前の形態の値未満にはしない」よう底上げ**する。
BST・ロール配分の計算はそのままに、結果だけを底上げするので、
「進化してもロールの個性は保ちつつ、どのステータスも必ず伸びる」の両立になる。

| モコハ系列（くさ・スターター） | HP | こうげき | ぼうぎょ | すばやさ |
|---|---|---|---|---|
| モコハ | 52 | 52 | 48 | 48 |
| ワカバネ | 70 | 70 | 65 | 65 |
| ジュランガ | 109 | 70 | 116 | 65 |

（底上げが効いた箇所: ジュランガの こうげき・すばやさ は、ロール変更前の素の計算値より高く底上げされている）

この底上げロジックを含めて、**155件の進化ステップすべてでステータス非減少**を `check2.mjs` で検証している。

### レベルごとの実数値

```
たいりょく = floor(種族値 × Lv ÷ 50) + Lv + 10
その他     = floor(種族値 × Lv ÷ 50) + 5
```

個体値・努力値は入れない。同じ種族なら同じレベルで必ず同じ数値になる。
「なぜか弱い個体」を引かないので、子どもが自分の育て方を疑わずに済む。

| 例 | 種族値（HP/こう/ぼう/すば） | Lv.10 | Lv.30 | Lv.50 |
|---|---|---|---|---|
| ふつう・第1形態・バランス | 49/49/46/46（計190） | HP29 / 14 / 14 / 14 | HP69 / 34 / 32 / 32 | HP109 / 54 / 51 / 51 |
| めずらしい・最終形態・ガード | 109/68/116/48（計340） | HP41 / 18 / 28 / 14 | HP105 / 45 / 74 / 33 | HP169 / 73 / 121 / 53 |
| とてもめずらしい・最終形態・アタッカー | 88/132/66/81（計367） | HP37 / 31 / 18 / 21 | HP92 / 84 / 44 / 53 | HP148 / 137 / 71 / 86 |
| でんせつ・単体・バランス | 119/119/109/109（計456） | HP43 / 28 / 26 / 26 | HP111 / 76 / 70 / 70 | HP179 / 124 / 114 / 114 |

## 2. ダメージ式

```
base   = floor( floor( (2 × Lv ÷ 5 + 2) × いりょく × こうげき ÷ ぼうぎょ ) ÷ 50 ) + 2
ダメージ = floor( base × タイプ一致 × 相性 × 急所 × 乱数 )

タイプ一致 = 1.5（じぶんと同じタイプのわざ）／ それ以外 1.0
相性       = 2 / 1 / 0.5 / 0（18タイプ表）
急所       = 1.5（1/16の確率）
乱数       = 0.90 〜 1.00
最低ダメージ = 1。ただし相性が0（こうかなし）のときは必ず0
```

> **仕様上の注意:** 旧実装は `Math.max(1, ...)` を無条件にかけていたため、
> 「こうかなし」のはずのわざでも1ダメージ入ってしまうバグがあった。
> `type === 0` のときは他の計算より先に0を返すよう直し、`check2.mjs` に専用テストを追加した。

### 同じくらいの相手と殴り合ったとき（いりょく60・等倍・一致なし）

| レベル | 1発のダメージ | 相手のHP | 何発で たおれる |
|---|---|---|---|
| Lv.10 | 8 | 32 | 4.0発 |
| Lv.20 | 13 | 64 | 4.9発 |
| Lv.30 | 18 | 91 | 5.1発 |
| Lv.40 | 22 | 137 | 6.2発 |
| Lv.50 | 27 | 169 | 6.3発 |

**4〜6発で決着**する。1ターン約8秒として、交代や演出を入れて 45〜90秒。

### 相性を分かって戦うと、どれくらい変わるか

Lv.30・いりょく60・アタッカー → ガード（相手HP 105）で計算。

| 状況 | ダメージ | 相手HPの | 何発 |
|---|---|---|---|
| なにも考えず殴る | 18 | 17% | 6発 |
| タイプ一致のわざ | 27 | 26% | 4発 |
| ばつぐんのわざ | 36 | 34% | 3発 |
| **一致＋ばつぐん** | 54 | 51% | 2発 |
| 一致＋ばつぐん＋急所 | 81 | 77% | 2発 |
| いまひとつ | 9 | 9% | 12発 |
| **こうかなし** | 0 | 0% | 当たらない |

**考えて選ぶと6発が2発になる。こうかなしを選ぶと0発（＝当たらない）。**
わざを選ぶ前に ◎ ○ △ × を出すので、読めなくても分かる。

## 3. タイプ相性の見せ方

| 表示 | 倍率 | 音 |
|---|---|---|
| ◎ ばつぐん | ×2 | 高く短い「キン！」 |
| ○ ふつう | ×1 | 通常 |
| △ いまひとつ | ×0.5 | 低く鈍い「ボスッ」 |
| × きかない | ×0 | 無音＋画面が一瞬グレー |

- わざボタンに常時つける。押す前に分かる
- タイプは**アイコンと色を主**にする（⚪ノーマル / 🔥ほのお / 💧みず / ⚡でんき / 🌿くさ / ❄️こおり …）
- 相手のタイプは画面上部に大きく1つ出す
- **相性を隠さない。** すでに知っている子から、知っている楽しみを取り上げない

### 複合タイプについて

**v1 は全員が単タイプ。複合タイプは v2 で入れる。** 理由:

1. ダメージ式には最初から `相性 = eff(わざ, タイプ1) × eff(わざ, タイプ2)` と書いておく。データに `type2` を足すだけで動く
2. 先に決めるべきは複合タイプではなく「4〜6発で決着するか」「進化が何日か」で、そこは単タイプでも検証できる
3. 今回の実装では単タイプに固定し、複合タイプは将来拡張として扱う

v2 で複合にする候補は先に決めておく（エリア3〜4の16系列）。

## 4. わざ

### 構成

1体が同時に持てるのは4つ。5つ目を覚えるときだけ「どれと入れ替える？」を聞く。
**忘れさせたわざは「おもいだす」でいつでも戻せる。**
5歳が押し間違えて主力を消す事故を、確認ダイアログではなく巻き戻しで防ぐ。

| いりょく | 位置づけ | 例 |
|---|---|---|
| 40 | 追加効果つきの小技。命中100 | 状態異常を狙う |
| 60 | 標準。序盤〜中盤の主力。命中100 | タイプ一致で使う |
| 80 | 強い。命中95 | 最終形の主力 |
| 100 | もっと強い。命中90 | 決めにいく |
| 110 | バーストわざ専用。命中95・**反動なし** | キョダイバースト中のみ（§11） |

> **仕様上の注意:** 旧仕様は「バーストわざ＝威力120・命中90・次のターン動けない」で、
> 2ターン平均の期待値が通常わざ連打より弱くなり得た。**「次のターン動けない」を撤廃**し、
> 威力と命中を調整（EV=104.5）して通常の主力わざ（EV=76）を明確に上回るよう固定した（§11で検算）。

補助わざ（ダメージ0）は「こうげきアップ」「ぼうぎょアップ」「かいふく」「状態異常」「**まもる**」の5系統。
まもるの正式仕様は §6 を参照。

### 覚えるレベル

進化レベルに合わせて決める。**進化した直後に必ず1つ覚える**ようにして、
「進化したら新しいわざが増えた」を毎回体験させる。

| タイミング | 覚えるもの |
|---|---|
| つかまえた時 | ノーマルの小技（40）＋ 自分のタイプの小技（40）＋ まもる |
| 1だんかい目の進化＋0 | 自分のタイプの標準わざ（60） |
| 1だんかい目の進化＋5 | 補助わざ（ロールに対応） |
| 2だんかい目の進化＋0 | 自分のタイプの強わざ（80） |
| 2だんかい目の進化＋6 | サブタイプの標準わざ（60） |
| 最終進化＋8 | **専用わざ（100）** — その子だけのわざ |

専用わざは名前も専用にする。図鑑の「わざ」欄に、まだ覚えていなくても
**名前だけ先に出す**（効果は「？？？」）。これが育てる目標になる。

### ロールと補助わざの対応

| ロール | 覚える補助わざ |
|---|---|
| アタッカー | こうげきアップ（自分・2段階） |
| ガード | ぼうぎょアップ（自分・2段階） |
| スピード | すばやさアップ＋つぎの一撃が必ず急所 |
| ヒーラー | かいふく（自分の最大HPの1/2） |
| サポート | 相手を まひ／どく にする |
| バランス | 相手のこうげきダウン |

## 5. 状態異常

4つだけ。**こんらん（自分を攻撃してしまう）は入れない。** 理不尽に見えるため。
**捕獲率には一切影響しない**（旧仕様の「ねむり・まひで捕獲率アップ」は方式Aへの一本化に伴い撤廃。§8）。

| 状態 | 効果 | 続く長さ | 見せ方 |
|---|---|---|---|
| やけど 🔥 | こうげき ×0.7 ／ 毎ターン 最大HPの1/16 | バトル終了まで | 赤い炎のアイコン |
| まひ ⚡ | すばやさ ×0.5 ／ 25%で うごけない | バトル終了まで | 黄色い火花 |
| どく 🟣 | 毎ターン 最大HPの1/8 | バトル終了まで | 紫のあわ |
| ねむり 💤 | うごけない | 1〜3ターン（攻撃を受けると起きる） | 青いZ |

- **バトルが終わればすべて治る。** 街に戻って薬を買う手順を作らない
- 同じ状態は重ならない。すでにやけどの相手にやけどは入らない（「きかなかった」と出す）
- ほのおタイプは やけどにならない／でんきタイプは まひにならない／どく・はがねは どくにならない
- サポートロールの価値は**純粋にバトル内の駆け引き**（相手の行動を縛る）に一本化した。捕獲との連動は無い

## 6. 手持ち・交代・行動順・まもる

| 項目 | 仕様 |
|---|---|
| 手持ち | 3体。ボックスからいつでも入れ替え（バトル外） |
| 場に出る | 1体 |
| 交代 | 1ターンぶんの行動を使う。相手より先に処理される |
| たおれたとき | 交代は無料（ターンを消費しない） |
| 全滅 | 「まけちゃった」→ その場でHP全快。ペナルティなし。チケットも減らない |
| 行動順 | すばやさが高いほう。同値は乱数 |
| にげる（バトル中） | 野生からはいつでも成功。ボスからは にげられない |

**負けても失うものを作らない。** 失うのは「今回はゲットできなかった」だけ。
チケットが減らないので、「もう一回！」がすぐ押せる。

> ※ 敗北画面の表示報酬と実際の付与結果が食い違わないよう、表示も同じ報酬計算結果を参照する。
> 新ゲームでは **負けの報酬を0にして表示もしない** ことで構造的に消す。

### まもる

前バージョンはボス戦UIに「こうたい／まもる／押し切る」が突然出てくるのに、
通常バトルアクションとして「まもる」が定義されていなかった。今回、以下で完全に確定する。

| 項目 | 仕様 |
|---|---|
| 使用条件 | **いつでも選べる**。PP・ゲージの消費なし |
| 効果 | そのターンに受けるダメージを **100%カット**（状態異常わざも防ぐ） |
| 連続使用 | **不可**。使用後1ターンは選べない。「つぎは まもるを つかえないよ！」と表示 |
| 成功率 | **100%**。外れない |
| ボス大技との関係 | ボスの「予告」ターンに使うと、大技のダメージを確実に0にできる |

毎ターン連打しても「安全なだけで勝てない」ので、追加の失敗率が無くても
自然と「大技を防ぐ」用途に使いどころが絞られる。中途半端な仕様のまま残さない。

## 7. 敵のレベルとAI

### レベル帯（プレイヤーに追従させない）

**敵レベルはエリアで固定**する。

| エリア | 野生のレベル | ボス | 出る だんかい |
|---|---|---|---|
| 1 | Lv.4〜10 | Lv.14 | 1だんかい目のみ |
| 2 | Lv.13〜20 | Lv.26 | 1だんかい目のみ |
| 3 | Lv.24〜32 | Lv.38 | 1〜2だんかい目 |
| 4 | Lv.36〜44 | Lv.52 | 1〜2だんかい目 |

**最終形は野生に出ない。** 進化させないと手に入らない。

### 「育てたら本当に強い」の検算

Lv.40 まで育てた最終形（めずらしい・アタッカー）を、エリア1の野生 Lv.6 にぶつける。

| | ダメージ | 相手のHP | 結果 |
|---|---|---|---|
| こちらの一撃 | 316 | 21 | **一撃で たおせる** |
| 相手の一撃 | 1 | 115 | 115発 耐える |

圧倒的になる。これが「強くなった」の正体で、レベル追従型では絶対に出せない感覚。
捕獲は勝利後の別フェーズ（§8）なので、**一撃で倒してしまっても捕獲チャンスは減らない**。
育てた子で序盤の未捕獲を埋めにいく行動が、そのまま気持ちよく成立する。

### 野生AI（かんたん）

1. 相性が ◎ のわざがあれば 70% でそれを選ぶ
2. なければ いりょくが一番高いわざ
3. HPが1/4以下になると 20% で「にげる」を試みる（レアほど逃げやすい）

相性を無視して殴ってこないので、**こちらのタイプ選択が意味を持つ**。
ただし70%止まりなので、たまに変なわざを撃つ。ここで勝てる余地を残す。

### ボスAI（かんがえる・入力読み禁止）

> **仕様上の注意:** 旧仕様「プレイヤーが交代したら、交代先に有利な技を使う」は、
> プレイヤーの入力を見てから行動を変える「入力読み」であり、5歳には「考えたのに敵がズルした」と
> 感じられる。**敵AIは、プレイヤーがそのターンの行動を選ぶ前に、内部で自分の行動を先に決定する**
> （`AI_READS_PLAYER_INPUT = false` として設計上明示。battle.mjs参照）。

1. 相性が ◎ のわざがあれば **必ず** それを選ぶ（ただし行動決定はプレイヤーの選択より前）
2. HPが半分を切ると1回だけ「こうげきアップ」を使う
3. 状態異常は半分の確率でしか入らない

### ボスの大技

> **何が問題だったか。** 旧仕様「1ターン溜め→威力100」は、溜めターンに何もしないため、
> 2ターン平均の期待値が通常わざ連打より弱くなり得た。「大きいのが来る！」と予告するなら、
> 通常わざより明確に強くなければならない。

修正後は、予告ターンもボスは黙って止まらず、控えめな威力で普通に攻撃する。

| ターン | ボスの行動 | 威力 |
|---|---|---|
| 予告ターン | 画面が赤く光り「つぎのターン、おおきいのが くる！」＋ 通常の一撃 | 50 |
| 次のターン | **大技発動** | 170（命中90%） |

2ターン平均の期待値 = (50 + 170×0.9) / 2 = **101.5**
ボスが通常わざ（威力80・命中95%）を連打したときの期待値 = **76.0**

**101.5 > 76.0** なので、予告どおり通常わざ連打より明確に強い。

予告ターン中に、プレイヤーは §6 の**まもる**（大技を確実に0にする）・**こうたい**（交代して被弾を避ける）・
**わざで押し切る**（一気に決めにいく）のどれかを選べる。**ボス戦の山場はこの1択。**

ボスHPは同レベル帯の1.6倍。2〜3分で決着する。

## 8. バトルと捕獲のつなぎ（方式Aに一本化）

> **仕様上の注意:** 旧文書には
> 「HPを削って赤くする→てかげんでHP1に制限→ねむり/まひで捕獲率アップ→戦闘中に捕獲」（方式B）と
> 「勝ってから、たおした相手に わ を投げる」（方式A）の**2つの捕獲フローが混在**していた。
> 本作は **方式Aに一本化**する。詳しい捕獲式・演出・野生出現テーブルは
> `07-wild-encounter-and-capture-design.md` に切り出した。ここではバトルとの接続だけを述べる。

```
通常のバトルを行う
  ↓
敵HPを0にして勝利する（「たおした！」）
  ↓
捕獲フェーズへ移行（バトル画面から切り替わる）
  ↓
わ を選ぶ → 最大3回まで捕獲判定 → 成功ならゲット／3回失敗なら にげられた
```

**捕獲判定は残りHP・状態異常に一切依存しない**（勝利した時点でHPは0のため、依存させる意味がない）。
したがって「てかげん」「HPを1残す」「ねむり・まひで捕獲率アップ」の仕組みは撤廃した。

この一本化の副作用として、§7の「育てたら本当に強い」問題が自然に解決する。
**一撃で倒してしまっても、捕獲フェーズは変わらず始まる**ので、育った子で序盤を周回して
未捕獲を埋める行動が何の障害もなく成立する。

## 9. XP と成長速度

### 曲線

```
つぎのレベルまでの合計XP: total(L) = round( 6 × (L − 1)^1.9 )
```

| Lv | 合計XP | Lv | 合計XP | Lv | 合計XP |
|---|---|---|---|---|---|
| Lv.5 | 84 | Lv.10 | 390 | Lv.15 | 903 |
| Lv.20 | 1,614 | Lv.25 | 2,515 | Lv.30 | 3,603 |
| Lv.35 | 4,875 | Lv.40 | 6,327 | Lv.45 | 7,956 |
| Lv.50 | 9,762 | Lv.55 | 11,741 | Lv.60 | 13,892 |

指数が 2 ではなく **1.9** なのが要点。Kids Quest参照実装は `6×(L−1)²` で、
2段目の進化に **19日** かかっていた（実測）。1.9に落とすと高レベルほど効いて、
最終進化が目安の日数内に収まる。

### 学習報酬

> **何が問題だったか。** `01-catch-and-evolution-design.md` は「ほしのわ=コアタスク1つごと、
> ぎんのわ=コア全クリア」、この文書は「チケット=コア5つで3枚、ぎんのわ=おかわり学習」と、
> **同じ行動に対して違う報酬の付き方**を書いていた。以降は `rewards.mjs` を唯一の正本とし、
> 01・06・新設の07とも、そこから生成する。

| きっかけ | もらえるもの | 上限 |
|---|---|---|
| コアタスクを1つクリア（4〜5問） | ほしのわ +1 | 1日5回まで |
| その日のコアタスク5つを全部クリア（＝基本ノルマ達成） | バトルチケット +3、ぎんのわ +1、たんけんポイント +2 | 達成ごとに1回 |
| 追加問題を1つクリア | バトルチケット +1、たんけんポイント +1 | **上限なし** |
| 追加問題4問セットで3問以上正解 | きんのわ +1 | **上限なし** |
| そのskillの習熟度が1段階上がる | たんけんポイント +2 | 達成ごとに1回 |
| 7日連続で学習した日 | つきのいし +1 | 達成ごとに1回 |
| 章末テストに合格 | にじのわ +1、たんけんポイント +5 | 達成ごとに1回 |
| エリアボスを初めて倒す | にじのわ +1、そのエリアのいし1種 +1 | 達成ごとに1回 |

| もらえるXP | 値 |
|---|---|
| 1問 正解 | 4 |
| コアタスク1つ 完了 | 20 |
| バトル 勝利 | 40〜80（相手のレベルによる） |
| ボス 勝利 | 300（初回のみ） |

**XPは手持ち3体すべてに同額入る。** 「出していない子が育たない」を作らない。
5歳が3体の育成を別々に管理するのは無理なので、パーティごと育つ。

### 追加チケットは上限なし

保護者要望として明確なため、**追加問題によるバトルチケット取得に1日の上限を設けない**。
「進化させたい」「レベルを上げたい」という理由で大量に勉強するなら、それを止めない。

### 難易度は「回数」ではなく「習熟度」で上げる

> **何が問題だったか。** 旧仕様「同じ科目を5回やったら学年+1」は粗く、
> 子どもから見て「頑張った罰として難しくなる」ように感じられかねない。

直近の正答率を見て、**できるようになった分だけ**難しくする。

| パラメータ | 値 |
|---|---|
| 見る範囲 | 直近8問 |
| 難しくする条件 | 正答率 85% 以上（最低6回は試行してから） |
| やさしくする条件 | 正答率 45% 以下（罰ではなく調整として） |

子どもから見た体験は「できるようになったから次へ進んだ」。回数で機械的に上げないので、
得意な子がいつまでも簡単な問題を繰り返す状態にも、苦手な子が置き去りにされる状態にもならない。

### 不正対策（連打・当てずっぽう防止）

| 対策 | 内容 |
|---|---|
| 複合判定 | 直近8問で複数の不自然シグナルが2個以上重なった場合のみ追加ゲーム報酬を一時保留 |
| 高速正答/同じ番号 | **単独では罰しない**。学習XPは通常どおり付与 |
| やさしい問題の周回 | 上の習熟度ベースの難易度上昇そのものが歯止めになる（同じ問題を繰り返すほど難しくなるので、周回のうまみが薄れる） |

## 11. ギガシンカ／キョダイバーストのバトル上の扱い

> **何が問題だったか。** データ上 `GIGA_SHINKA`（12体）と `KYODAI_BURST`（8体）は重複0で、
> 「種族ごとにどちらか一方だけ」がすでに成立していたのに、旧・画面案は
> 「この子をギガにする？キョダイにする？」と**同じ1体について選ばせる**ように描かれていた。
> 正しいUIは「パーティの誰の切り札を使うか」を選ぶもの。加えて、ギガの性能表現が
> 「HP+50/攻撃+50」「全能力×1.35」「ちから+50%」の3通り併存していたのも1つに統一した。

| | ギガシンカ | キョダイバースト |
|---|---|---|
| 対象 | 最終形 12体（12タイプ・1タイプ1体） | 最終形 8体 |
| 対象種族の重複 | **0（種族ごとに排他）** | 同左 |
| 必要なもの | ギガキー ＋ その子のギガコア | バーストのしるし |
| アイテムの消費 | **しない**（永久） | **しない**（永久） |
| 回数 | パーティ全体で1バトルに1回 | 同左 |
| 続く長さ | **バトル終了まで** | **3ターン** |
| ステータス | **全ステータス ×1.35**（この1つだけ。他の表現は使わない） | たいりょく ×2／こうげき ×1.2 |
| わざ | そのまま（威力が上がる） | 主力わざが **バーストわざ（いりょく110・命中95%・反動なし）** に置き換わる |
| 戻ったとき | バトル終了時に通常へ。HP割合を保持 | 3ターン後にHP割合を通常最大HPへ戻す。**0HPは0のまま** |
| 向いている場面 | 長期戦・確実に勝ちたい | ボスの大技前・一気に押し切る |

**種族ごとにギガシンカかキョダイバーストのどちらか一方だけを持つ。**
パーティにギガ対象・バースト対象が両方いることはあるが、
**1バトルで使える特殊変身は合計1回だけ**。プレイヤーが選ぶのは
「この子をギガにするかバーストにするか」ではなく、**「今回の切り札を、どのモンスターに使うか」**。
画面上部に「このバトルで つかえる とくべつなちからは 1つだけ！」と常時出す。

### バーストわざが「使うと損する技」にならないことの検算

EV(バーストわざ) = 110 × 0.95 = **104.5**
EV(通常の主力わざ) = 80 × 0.95 = **76.0**

**104.5 > 76.0** なので、反動を無くしただけで通常わざを上回る。
「3ターン限定」という制約自体がすでにコストなので、わざ自体に追加の反動は付けない。

### キョダイバースト解除時のHP

変身中のHP割合を通常最大HPへ戻す。0HPは0HPのままで、最低1HP保証は入れない。

| | できごと | もらえるもの |
|---|---|---|
| 1 | コアタスクを1つクリア（×5、22問） | 約170 XP ＋ **ほしのわ +1×5** |
| 2 | その日のコアタスク5つを全部クリア | **バトルチケット +3 ＋ ぎんのわ +1** |

**ふつうランクを捕まえるぶんには常に足りる。**
足りなくなるのは「めずらしい以上にきんのわを連投した」ときだけで、
それは自分で選んだ結果なので納得できる。

## 13. 実装順（縦切り検証）

> **何が問題だったか。** 旧・縦切り18体にはギガシンカ対象は含まれていたが、
> キョダイバースト対象が0体だった。239体すべてを作る前に、捕獲・育成・進化・ギガシンカ・
> キョダイバーストまで一通り実機検証する必要があるため、**キョダイバースト対象の系列を1つ追加**する。

最初に作るのは 7系列・21体。

## 14. 長期運用の簡易シミュレーション

手持ち3体だけで、84系列すべてを最終形まで育て切るとどれくらいかかるか。
学習XPは手持ち3体全員に入る前提（現行仕様のまま。「そだてる枠」は追加しない）で、
3体を並行して回し続けるジョブスケジューリングとして簡易シミュレーションした。

総系列は 84。このシミュレーション対象は **進化系列 79系列**。単体5系列は進化工程がなく最初から完成状態なので除外（79+5=84）。

| 経過日数 | 完成した系列 | 割合 |
|---|---|---|
| 30日 | 3系列 | 4% |
| 90日 | 12系列 | 15% |
| 180日 | 27系列 | 34% |
| 365日 | 56系列 | 71% |

**全79系列を完成させるまで、目安で約529日（約17.6か月）。**

1年経っても図鑑の完全制覇までは届かない見込みで、**進化待ちがかなり詰まる**。
ただし、これは「毎日フルで遊び続ける想定」でもこの程度、というだけであり、
v1で緊急に対処すべき問題とまでは考えていない（エリア1〜2だけでも数十種類は現実的な期間で遊べる）。

**v1では対応しない。** 将来、体感的に進化待ちが辛いという声が出た場合の案として、
「そだてる枠」を1〜2体追加し、学習XPの一部（例: 30%）をそちらにも配分する仕組みを検討する。
手持ち3体の戦闘バランスには影響させない（そだてる枠はバトルに出せない、育成専用の枠にする）。

## 15. この文書の数値の出どころ

```bash
node scripts/battle.mjs        # XP曲線・ステータス・ダメージ・進化日数を再計算
node scripts/capture.mjs       # 捕獲の1投／3投累積成功率
node scripts/items.mjs         # いし・もちものの入手エリア
node scripts/wildEncounter.mjs # 野生出現プールの分類・rank軸の分離
node scripts/simulate.mjs      # 長期運用の簡易シミュレーション
node scripts/check2.mjs        # 図鑑データの整合性（全項目）
node scripts/gen-battle-md.mjs # この文書を再生成
```

捕獲式 `P = (a/255)^(3/4)` は本作の確率モデルとして固定し、
a = 10 / 45 / 90 / 135 / 180 / 200 / 254 の代表点で計算結果を回帰テストする。
18タイプ相性表は 324通りを機械検算（ばつぐん51／いまひとつ61／こうかなし8／等倍204）。
