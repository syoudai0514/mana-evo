## この資料の目的

専門家・AI向けの設計書とは別に、「ManaEvoが今どういうゲームなのか」「なぜそのルールなのか」「変更すると何が変わるのか」を専門用語をできるだけ使わず説明するための資料です。

この資料は `design/current/**` の代わりではありません。正確な実装契約は専門設計書を正本とし、この資料はその内容をオーナーが理解・判断できる言葉へ翻訳したCURRENT companionです。

## 恒久運用ルール

1. ManaEvoの設計を変更する場合、専門設計書だけを更新して完了してはいけません。
2. 同じproduct-changeで、この資料の該当箇所も更新します。
3. 変更時には、オーナーへ「今までどうだったか / 何を変えたか / なぜ変えたか / 子どもの体験がどう変わるか / 注意点」を分かりやすく表示します。
4. 内部ID、DB、関数名などを理解しないと判断できない説明は禁止します。必要な専門用語には日本語の意味を併記します。
5. 専門設計書と本資料が食い違った場合は専門設計書を正として、同じ変更セット内で本資料のdriftを修正します。
6. 初回の全体版は再建の最終release時までに完成させます。それまでも新しい設計変更が発生した領域は、その都度この資料へ反映します。
7. release後も恒久的に最新化します。

## 変更説明の標準フォーマット

設計変更をオーナーへ報告するときは最低限、次の5点を示します。

- **これまで:** 変更前はどういうルールだったか
- **変更後:** 新しいルールは何か
- **理由:** なぜ変更するのか
- **子どもへの影響:** 実際の遊び・学びがどう変わるか
- **守ること:** 悪用防止、公平性、データ保持など重要な安全条件

## 最新の設計変更: 学習とバトルチケット

### これまで

追加学習で正解した回数をもとにバトルチケットを増やす仕組みはありましたが、「簡単な同じ問題だけを大量に解く」「無料練習までカウントされる」など、学習よりゲームを効率よく進める攻略法が生まれる余地がありました。

### 変更後

毎日の基本学習を終えたあと、意味のある追加学習で **5問正解するとバトルチケットを1枚**もらう方式にします。

ただし、同じ種類の知識だけで5問を埋めることはできません。1枚のチケットに使える同じ知識の正解は最大3問までです。たとえば「たし算3問 + ひき算2問」はOKです。

忘れかけた頃に出る復習問題や、一度間違えたあと少し時間を空けて自力で解き直した問題も、普通の正解1問として扱います。

一方、答えを見た直後に同じ答えを押すだけの問題、すでに十分できる簡単な問題の不要な繰り返し、無料・おかわり練習、誤答そのものはチケット獲得には数えません。

### 理由

目的は「長時間画面を見た子」や「ゲームの仕組みを攻略した子」を有利にすることではなく、**実際に学習した分だけ自然に遊べる**状態にすることです。

正解までの秒数には条件を付けません。本当に理解していて1〜2秒で解ける子を、わざと待たせることはしません。

### 子どもへの影響

得意な子は速く解いても損をしません。苦手な子も、間違えたこと自体で罰を受けず、その後に自力で思い出せれば正解1問分として回収できます。

同じ簡単な問題だけを連打するより、少し違う知識も学んだ方が自然にチケットへつながります。ただし「算数・国語・英語を必ず混ぜる」といった教科の強制はしません。

### 守ること

- 5問正解 = 1チケット
- 同じ知識は5問中最大3問
- 正解が速いことを罰しない
- 難しい問題だからチケットを増やすこともしない
- 間違いをわざと増やして得する仕組みにしない
- 答えを見ただけではカウントしない
- 無料・おかわり練習からチケットを増やさない
- 端末再読み込みやプロフィール切替で同じ正解を二重カウントしない
