# 捕獲・進化・学習報酬 正本仕様

## 1. ゲームの中心ループ

**捕まえたい / 育てたい / 進化させたい / 次を見たい → だからもう少し学ぶ** を最優先にする。

- 今日の基本学習5問を完了 → バトルチケット3枚
- 同時に ほしのわ3個
- 追加学習は有効な正解1問 → チケット+1
- 追加学習3正解ごと → ほしのわ+1
- 単元MASTER → ぎんのわ+1
- 「むずかしい」MASTER → きんのわ+1
- 章末/学年級の大達成 → にじのわ候補。具体的な達成点への割当は、その学習UI接続時に確定する

## 2. バトルチケット

- 有効期限は**獲得日を含む7日間**。
- 期限が近いチケットから先に使う。
- 今日の基本5問が未完了なら、前日までのチケットを持っていても**新規バトルは開始不可**。
- バトル開始時に1枚をreserve/消費し、消費元の獲得日・期限を `activeBattle` に保存する。
- **勝利 / 捕獲成功: 消費確定。返却しない。**
- **敗北: 1枚返却。**
- **プレイヤーが明示的に逃げる/やめる: 1枚返却。**
- Safari終了 / reload / crash: `activeBattle` を復元し、同じバトルを続行。追加消費しない。
- 返却は二重に行わない。

## 3. 「わ」

4種類は永久所持・期限なし。

| 種類 | 初期倍率 | 備考 |
|---|---:|---|
| ほしのわ | ×1.00 | 標準 |
| ぎんのわ | ×1.20 | 上位 |
| きんのわ | ×1.50 | 上位 |
| にじのわ | 100% | 必ず成功 |

- 非にじの最終成功率は92%を上限とする。
- 上記倍率・92%上限はconfig化し、実プレイのバランステストで調整可能にする。
- 1バトル最大3投。
- 捕獲失敗はターンを消費し、敵が行動する。
- UIでは種類別の所持数と実成功率を投げる前に表示する。
- 捕獲演出は4段階の「わ＋星」を維持する。

## 4. 通常進化

最低限、実マスタに以下3方式を持つ。

1. `level`
2. `stone`
3. `held_item_level`

- 石進化は石を消費する。
- もちもの進化は必要アイテムを持たせ、必要Lv条件を満たして進化する。装備中のもちものは進化後も保持する。
- 一般/レアモンスターは原則進化可能。進化なしはボス/神格級等の明確な例外だけ。
- 進化条件をUIに常時見せる。

## 5. 特殊形態

### ギガシンカ

- 原則、対象種族の最終形。
- 1バトル1体。
- 発動後は戦闘終了まで継続。
- ギガキー: 1個、永久所持、非消費。
- 種族専用ギガコア: 永久解放、非消費。
- 基本ループ: **最終進化 → 専用チャレンジ/ボス解放 → 勝利 → その種族のギガコア獲得 → 永久解放**。
- 対象種族の最終一覧と個別チャレンジ割当は別マスタで確定する。

### キョダイバースト

- 一部の対象最終形。
- 1バトル1回、3ターン限定。
- 巨大化 + 専用技 + HP上昇。
- 3ターン後に通常へ戻る。
- ギガシンカと同時使用不可。
- バーストのしるし: 対象ごとの永久解放・非消費。
- 対象種族と具体的取得チャレンジ割当は別マスタで確定する。

### 不採用

- スター覚醒
- スター覚醒用の「スターのかけら」
