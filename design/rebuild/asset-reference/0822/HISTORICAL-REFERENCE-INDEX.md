# 2026-08-22 Historical Monster Visual Reference Pack

Status: **REFERENCE ONLY — NOT CURRENT CANONICAL / NOT APPROVAL EVIDENCE**

Source: user-provided `0822まとめ.zip` supplied during Phase 4 planning.

## Why this pack is preserved

The pack contains 34 historical ManaEvo monster-design/review boards covering broad portions of the former 239-species concept set, including type-grouped design boards, area review boards, late-number individual proposal boards, and whole-set review summaries. It is valuable as visual continuity evidence and should be consulted before regenerating a species.

It must **not** override CURRENT identity/specification documents. Stable IDs, current names, active scope m001-m238, family/stage/type, and canonical descriptions still come from `design/current/**`. Historical No.239 remains excluded.

## Phase 4 usage rule

For every species/family art task:

1. Resolve CURRENT species/family description first.
2. Check CURRENT candidate assets if present.
3. Check this historical visual reference for prior composition, silhouette, palette, evolution direction, and type presentation.
4. Preserve useful historical visual identity when it remains compatible with CURRENT.
5. Regenerate only when the prior proposal conflicts with CURRENT, is too similar to another family, fails age/readability/originality rules, or is technically unusable.
6. Never copy historical labels/names/species counts blindly; visual reference only.

## Important planning consequence

Phase 4 production is organized primarily by **type/attribute**, not contiguous No ranges. Keeping the same type under one art-direction owner reduces accidental reuse of the same silhouette, elemental aura, horns/wings, color formula, or body template across separate workers.

Within each type, families remain whole and are reviewed together. Global style is shared across all types, but each type owner is responsible for deliberate cross-family differentiation inside that attribute.
