# バトル・進行 正本仕様スナップショット

更新日: 2026-08-24

## 1. バトル基本

- 18タイプ
- 手持ち3体
- 場に出るのは1体
- 各モンスター4技
- 交代可能
- タイプ一致・タイプ相性を重要にする
- 技を選ぶ前に相性を表示
- 個体値・努力値・性格のような隠し補正は初期版では導入しない。同じ種族・同じLvなら同じ能力値
- Lv上限は100
- 育てた結果として過去の敵を圧倒できることは成長実感として許容する

## 2. 種族基礎値とレベル成長

全モンスターは次の4つの種族基礎値を持つ。

- `base.hp`
- `base.attack`
- `base.defense`
- `base.speed`

実能力値はポケモン系RPGの「種族値×レベル」の考え方を簡略化して以下で算出する。

```text
HP       = floor((2 * base.hp      * Lv) / 100) + Lv + 10
こうげき = floor((2 * base.attack  * Lv) / 100) + 5
ぼうぎょ = floor((2 * base.defense * Lv) / 100) + 5
すばやさ = floor((2 * base.speed   * Lv) / 100) + 5
```

- 進化してもLv・XP・instanceIdは維持
- 進化後は種族基礎値だけ切り替わるため、同じLvのまま能力値が上昇する
- 238体の基礎値は進化後に各能力が下がらないことをvalidatorで保証する
- 能力配分は合計値だけでなく役割を持たせる: バランス / 物理アタッカー / 高速アタッカー / タンク / HP耐久 / 防御耐久 / 鈍足高火力 / 高速低耐久

## 3. ダメージ

初期版は次の式を採用する。

```text
baseDamage = floor(((((2 * Lv / 5) + 2) * 技威力 * 攻撃 / 防御) / 50) + 2)
damage = floor(baseDamage * STAB * タイプ相性)
```

- STAB（タイプ一致）: `1.20`
- タイプ相性: 既存18タイプ表を使用（0 / 0.5 / 1 / 2、複合は乗算）
- 初期版はダメージ乱数を入れず、子どもが結果を理解しやすい決定論的計算とする
- 素早さは主に行動順へ影響させ、火力への寄与は戦力評価上のみ小さく扱う

## 4. 戦闘力 `combatPower`

単純なLvだけで敵を調整しない。進化形・役割差を含めて以下の内部戦力を使う。

```text
effectiveDurability = HP * (1 + Defense / 100)
effectiveOffense    = Attack * (1 + Speed / 300)
combatPower          = sqrt(effectiveDurability * effectiveOffense)
```

タイプ相性は `combatPower` に入れない。有利タイプを選ぶこと自体を攻略上のメリットとして残す。

### 4.1 プレイヤー基準戦力

弱い1体へ付け替えて敵を意図的に弱くすることと、1体だけ極端に高Lvで全体を引っ張りすぎることの両方を避ける。

```text
activePower   = 編成中の上位3体の平均 combatPower
rosterCore    = 所持キャラ上位5体の中央値 combatPower
referencePower = max(activePower, rosterCore * 0.9)
```

## 5. 通常敵

通常敵は固定Lvではなく、現在の `referencePower` を基準にソフトスケーリングする。

| 区分 | 目標戦力 |
|---|---:|
| weak | ×0.82 |
| normal | ×0.92 |
| strong | ×1.02 |
| rare | ×1.065 |
| elite | ×1.12 |

敵種族の基礎値から、目標戦力に最も近くなるLv1〜100を逆算する。

目標ターン数:

- weak: 2〜4ターン
- normal: 3〜5ターン
- strong: 4〜6ターン
- rare: 4〜7ターン
- elite: 5〜8ターン

通常敵はプレイヤーより少し弱めを中心にし、育成した強さを感じられる余白を残す。

## 6. ストーリー/エリアボス

### 6.1 初回だけ合わせ、その後は固定

ストーリー/エリアボスは**初回挑戦開始時**の `referencePower` から強さを確定し、その値をセーブする。2回目以降の通常再戦では再計算しない。

これにより:

- Lv15で初めて会ってもLv80で初めて会っても初見として成立する
- 負けた後に学習・レベル上げ・進化をすればボスは追従せず確実に有利になる
- タイプ選択・技構成・チーム編成の工夫をボス側が相殺しない

### 6.2 ボスRank

| Rank | 最終目標戦力 | HP補正 | 攻撃補正 | 防御補正 |
|---|---:|---:|---:|---:|
| C | reference ×1.02 | ×1.20 | ×1.02 | ×1.00 |
| B | reference ×1.08 | ×1.35 | ×1.04 | ×1.03 |
| A | reference ×1.14 | ×1.50 | ×1.07 | ×1.05 |
| S | reference ×1.20 | ×1.65 | ×1.10 | ×1.08 |
| EX | reference ×1.28 | ×1.80 | ×1.12 | ×1.10 |

**重要:** `最終目標戦力` は上記HP/攻撃/防御補正を適用した後の `combatPower` が目標に近づくようLvを逆算する。目標戦力に加えて補正を二重加算しない。

素早さは原則として種族どおり。ボスだから必ず先手にはしない。

### 6.3 保存値

```text
bossBalanceSnapshots[stageId] = {
  stageId,
  bossId,
  bossRank,
  lockedLevel,
  referencePower,
  targetPower,
  statMultipliers: { hp, attack, defense, speed },
  balanceVersion
}
```

一度作られたsnapshotは、通常再戦では将来balanceVersionが上がっても尊重する。既に挑戦したボスがアップデートだけで突然強くなることを防ぐ。

### 6.4 再挑戦の体感

| 初回からのプレイヤー戦力成長 | 目標体感 |
|---:|---|
| +0〜5% | ほぼ同じ |
| +10% | 少し有利 |
| +20% | 明確に有利 |
| +35% | かなり楽 |
| +50%以上 | 圧倒してよい |

初回確定後に十分育ててワンパン級になることは、学習・育成成果として許容する。強制HPゲートは初期版では採用しない。

## 7. チャレンジ再戦

通常クリア済みボスに別枠の `チャレンジ再戦` を用意する。

- チャレンジ再戦のみ毎回現在の `referencePower` で再スケーリング
- 通常再戦snapshotは上書きしない
- 特別報酬はチャレンジ用マスターで設定する

これにより「昔のボスを圧倒して成長を感じる」と「今の強さで歯ごたえある再戦」を両立する。

## 8. 難易度表示

画面では推奨Lvではなく、現在戦力との差から子ども向けに表示する。

- 🟢 `いけそう`
- 🟡 `いいしょうぶ`
- 🔴 `かなりつよい`

Lvは表示してよいが、攻略判断の主表示は戦力差ラベルとする。

## 9. HP / 交代

- HPは手持ち個体ごとにバトル内保持
- 交代で回復しない
- 瀕死個体へ交代して復活できない
- activeが瀕死でも控えが生存していれば強制交代

## 10. バトル中断とチケット

- 新規開始には今日の基本5問完了が必要
- 開始時に期限近いチケットを1枚reserve
- `activeBattle` をセーブし、reload/crash後も復帰
- 敗北/明示逃走はreserveした1枚を返却
- 勝利/捕獲成功で消費確定

## 11. 捕獲

- 敵HP50%以下から捕獲可能（初期値。プレイテストで調整可）
- 1バトル最大3投
- 失敗は敵ターン
- 4種類の「わ」と性能は `01-catch-and-evolution-design.md` を正とする

## 12. XP / 進化体験

XP・技威力・捕獲base chanceの**初期値は必ず設定して実装する**。最終値はシミュレーションと実プレイで微調整する。

進化体験の目安:

- 最初の相棒: 初回進化 2〜4日 / 最終 10〜14日
- 一般3段階: 初回 3〜7日 / 最終 14〜28日
- レア3段階: 初回 7〜14日 / 最終 21〜40日
- 追加学習を頑張った日は早まってよい

## 13. QA / 受け入れ条件

- Lv1 / 5 / 10 / 20 / 30 / 50 / 100で全種族の能力値を計算できる
- 進化直前→進化直後でHP/攻撃/防御/素早さが下がらない
- 通常敵の戦力比が区分レンジから大きく外れない
- ボス初回snapshotが保存され、育成後の通常再戦でlockedLevelが変わらない
- チャレンジ再戦では現在戦力へ再スケーリングする
- タイプ有利を選んでも敵戦力の再補正を行わない
- 通常敵の一撃死・ボスの理不尽な高火力・耐久無限化をシミュレーションで検出する
