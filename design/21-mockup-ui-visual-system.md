# ManaEvo モックアップUI・ビジュアル正本

更新日: 2026-08-25
ステータス: **正本仕様（ユーザー承認済み・実装済み）**

## 1. 目的

ManaEvoを「データ一覧」ではなく、子どもが次の行動を直感的に選べる学習RPGとして見せる。承認されたモックアップの青・白・金を基調としたゲームUIを実装基準とする。

> モックアップ内のルミナ等のキャラクター、背景イラスト、サムネイルはビジュアル方向を示す参考表現であり、runtimeの正式モンスターmasterや正式画像を置き換えない。実装画面では既存の正式画像があるspeciesを優先し、未完成speciesだけ既存placeholderを使う。

## 2. ホーム

画面上から次の順で意味が伝わること。

1. マナエボのブランドと相棒
2. **まなぶ → チケットGET → ぼうけん → バトル → つかまえる → そだてる・シンカ**
3. 今日のチケット / マナ / 実際の現在地 / 相棒Lv
4. 今日の学習進捗と「まなぶ」「ぼうけん」CTA
5. ゲーム説明と次の進化目標

## 3. ぼうけん

- 上段にArea1〜4を一本のルートとして表示する。
- 現在地を強調し、未解放エリアはロック表示する。
- エリア内は **入口 → 中盤 → 奥地** の3ノード。実際の解放条件と見た目を一致させる。
- 通常表示は「きょうの であい」最大5件。野生・シンカしれん・特殊しれん・ボスを混ぜ、未GET / 初回 / 育成向け / おすすめ等の意味タグを表示する。
- 全件確認は「ほかも さがす」。

## 4. バトル

- 技4枠を色分けして視認性を上げる。
- 捕獲可能時の主CTAは **「わを なげる」**。HP50%以下の条件をその場で明示する。
- リング種別の選択は既存4種と捕獲率ロジックを維持する。
- 画面内に「HP50%以下」「1バトル3回」「チーム3体」「勝利で経験値」の4ポイントを短く表示する。

## 5. そだてる・シンカ

- モンスター画面の主目的を「そだてる・シンカ」として見せる。ボックス/図鑑は同画面の機能として維持する。
- シンカ条件は **レベル / いし / もちもの＋次のLv** の3系統を常時理解できるよう表示する。
- 「GET直後の即進化を避ける」「自分で育てて進化」「自力進化で第2形態の場所が開く」を説明する。
- バトル結果で進化可能になった場合は **「✨ いま シンカする！」** から全画面進化演出へ直接つなぐ。

## 6. 共通ビジュアル

- 基調: 青 / 白 / 金。成功=緑、ボス=赤、試練=紫。
- 大見出しは青いゲームパネル。主要CTAは金〜オレンジ。
- 子ども向けに、太字・短文・大きなタップ領域・アイコン併用。
- 下部ナビは **ホーム / まなぶ / ぼうけん / モンスター / あそびかた** の5枠固定。
- iPhone縦画面を第一基準とする。
