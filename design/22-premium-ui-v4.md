# ManaEvo Premium UI v4

Status: 正本UI仕様（2026-08-25 ユーザー実機レビュー反映）

## 目的

承認済みモックの完成度を実装画面まで引き上げる。特に **ぼうけん** と **モンスター** を、カード一覧ではなく「遊びたくなるゲーム画面」として成立させる。

## 1. iPhone safe area

- `viewport-fit=cover` を前提に `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)` を必ず使う。
- 上部ヘッダーのロゴ・所持品は Dynamic Island / 時計 / 電波表示の下に配置する。
- 下部5タブもホームインジケータに重ならない。
- iPhone WebKit E2EをPR必須確認とする。

## 2. ヘッダー所持品

記号単独は禁止。常時ラベルを付ける。

- 🎫 **チケット**: ぼうけん開始で1枚使う。
- 💎 **マナ**: まなびで生まれる成長のちから。
- ⭐ **ほしのわ**: モンスターをGETするときに使う捕獲アイテム。

「⭐」は経験値・評価・クリア星ではなく **ほしのわ** を意味する。子どもが迷わないよう `ほしのわ` と文字で表示する。

## 3. ぼうけん画面

### 3.1 世界を先に見せる

- Area1〜4を一本のワールドルートとして描く。
- 現在地は金色リング + `NOW` で強調。
- 未解放エリアはロックと彩度低下。
- Areaごとに背景テーマを変える。
  - Area1: 草原・森
  - Area2: 火山・砂
  - Area3: 氷海・深森
  - Area4: 星・天空

### 3.2 エリア内

- 入口 → 中盤 → 奥地を3ノードの道として見せる。
- 今いるゾーンは浮き上がる金色強調。
- 推奨Lvと「かなりつよい」を一目で判別できる。

### 3.3 今日の出会い

- 通常は意味のある最大5件だけを大型カードで出す。
- モンスター画像を主役にする。
- `未GET / 育成向け / 初回 / おすすめ` の意味タグを表示。
- `ほかも さがす` で全件検索へ切替可能。

## 4. モンスター画面

### 4.1 チームを主役にする

- 初期タブは3体チームを大きく横並び表示。
- 正式画像は背景枠を外し、立ち絵として見せる。
- 選択中は金色リングと浮き上がりで強調。
- 名前 / Lv / タイプ / 進化までを1カード内で判断できる。

### 4.2 育成詳細

- 選択した1体の立ち絵を大きく表示。
- HP / こうげき / ぼうぎょ / すばやさを4チップ表示。
- 進化領域を金色の報酬カードとして最優先表示。
- `✨ いま シンカする！` を最重要CTAとする。
- ギガシンカ / キョダイバーストは通常進化の下に置く。

### 4.3 図鑑

- 3列グリッドを基本とする。
- 未発見=シルエット、発見=開示、GET=カラー登録。
- `GET x/238` と `はっけん x/238` を上部に常時表示。

## 5. あそびかた

- 長文説明書ではなくゲーム内ガイドとして見せる。
- 現在の仲間と次の進化目標を大きく見せる。
- 「ほしのわ」を星アイコンだけで表現しない。

## 6. 既存仕様を壊さない

このUI改修では以下を変更しない。

- Kids Quest学習ロジック
- 1日3チケットの基本報酬
- 捕獲HP50%以下 / 1バトル3投
- 4種の「わ」
- エリア / ゾーン解放条件
- 通常進化 / ギガシンカ / キョダイバースト
- 238体マスター
