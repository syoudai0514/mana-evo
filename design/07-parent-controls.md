# 07 保護者機能・子ども画面の権限境界

## 目的

ManaEvoは子どもが自分で難易度を下げたり、学年を戻したり、先取り学年を開放したりしてゲーム報酬を取りやすくできないことを必須要件とする。

## 子ども画面で変更禁止

以下は子ども画面に操作UIを置かない。

- 現在の学習学年 `grade`
- 先取り解放 / 解放済み最高学年 `gradeMax`
- `ふつう / むずかしい` の切替
- つくよみちゃん / 端末音声 / 読み上げ速度 / 音量
- 子どもプロフィールの作成・切替
- 学習データのimport/export
- どうとくの保護者設定

子ども画面では現在の学年を表示するだけとし、「がくねんと むずかしさは おうちのひとが きめる」と表示する。

## 学年進行

- 必須単元と「ほしのしれん」の条件を満たすと次学年を **解放** できる。
- 解放されても子ども自身は学年を切り替えられない。
- 子ども画面では「つぎの がくねんが ひらいたよ。おうちのひとに きいてね」と案内する。
- 実際にどの学年を学習するかは保護者メニューで `SET_GRADE` する。
- 保護者は必要な場合のみ `FORCE_GRADE_MAX` で先取り解放できる。
- 誤って解放した場合は `LOWER_GRADE_MAX` で戻せる。

## 保護者メニュー

ホーム画面に `🔒 おうちのひと` を常設する。

入口では4桁の保護者PINを要求する。初回PIN設定・PIN再設定時は、子どもの誤操作を防ぐため簡単な大人確認問題を追加する。

このPINは認証基盤ではなく、同一端末上での子どもの誤操作防止用ロックである。

## 保護者メニューの主要導線

最上部から次へ1タップで移動できること。

1. 学年・先取り
2. つくよみちゃん
3. むずかしさ
4. プロフィール
5. バックアップ

### つくよみちゃん

保護者メニュー内で以下の順序を明示する。

1. `つくよみちゃん` を選択
2. `つくよみちゃんを端末に保存`
3. `声をテスト`

モデル保存・音声エンジン・iPhone実機対策はKids Quest学習基盤を正本とする。

## 学習画面の表示境界

Kids Questの `ActivityPlayer` 等は全画面学習UIとして扱う。
ManaEvo共通ヘッダーとKids Questの学習ヘッダーを同時に重ねない。

対象:

- ActivityPlayer
- FreeStudyScreen
- ReviewScreen
- ChapterTestScreen
- EnglishDictionaryScreen
- ParentScreen

これらの画面ではManaEvo共通ヘッダーを非表示にし、各Kids Quest画面のヘッダーだけを表示する。

## 回帰テスト必須

CIで最低限以下を固定する。

- StudyHubに `SET_GRADE` / `FORCE_GRADE_MAX` / `LOWER_GRADE_MAX` を置かない
- StudyHubに学年ピッカーを置かない
- 保護者メニューはPIN gate経由でのみ開く
- ホームから保護者メニューへ到達できる
- つくよみちゃん設定へのショートカットがある
- 全画面学習時にManaEvo共通ヘッダーを重ねない
