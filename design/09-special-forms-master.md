# ギガシンカ／キョダイバースト 対象マスター

更新日: 2026-08-24

この文書は、実装前設計パッケージ `mana-evo-terra-FINAL-CORRECTED` の `scripts/forms.mjs` / `02-dex.md` / `01-catch-and-evolution-design.md` から回収した対象割当を、現行ManaEvoの正本へ復元したもの。

## 優先ルール

- 対象種族の具体割当はこの文書を正とする。
- 現行ゲーム有効範囲は No.001〜238。元パッケージの239体表記は旧スコープだが、下記20体はすべてNo.001〜238内なので対象割当には影響しない。
- スター覚醒は使わない。
- ギガシンカとキョダイバーストは種族単位で排他。同じ種族が両方を持たない。
- でんせつ級は対象外。
- 1バトルで使える特殊変身はパーティ全体で合計1回。

### ギガの必要物／効果

- ギガキー: 1個・永久・非消費。物語序盤で入手。
- ギガコア: 種族ごとに1個・永久・非消費。
- ギガコア取得: 対象種族を最終進化まで育てる → その種族の専用チャレンジ/ボスが解放 → 勝利で取得。
- 持続: バトル終了まで。
- 効果: 全ステータス ×1.35。
- HPは変身前後で割合維持。
- 初回ギガ時に「ギガのすがた」を図鑑解放。図鑑番号は増やさず同一枠の別タブ。

### バーストの必要物／効果

- バーストのしるし: 種族ごとに1個・永久・非消費。
- 取得: 対象種族を最終進化まで育てる → 専用チャレンジ/ボス解放 → 勝利で取得。
- 持続: 3ターン。
- 効果: HP ×2.0 / 攻撃 ×1.2。
- 主力技をバースト技へ置換: 威力110 / 命中95% / 反動なし。
- 発動・解除ともHP割合を維持し、0HPは0のまま。

## 実装受入条件

- 上記12+8体が238体マスター内にすべて実在する。
- すべて最終形である。
- ギガ12体とバースト8体の重複が0。
- ギガ対象は12タイプに分散する。
- `gigaEligible` / `burstEligible` は名前文字列ではなく正式IDで保持する。
- ギガコア／バーストのしるしは種族正式IDをkeyにした永久所有権としてセーブする。
- QAモードでは対象20体を最終形・必要物所持済みで確認可能にする。
