# Mana Evo（マナエボ）

Kids Quest の**完成済み学習基盤を変えずに使い**、ゲーム部分だけを ManaEvo として発展させるリポジトリです。

## 絶対方針

- `syoudai0514/kids-quest` 本体は変更しない
- **学習フロー・問題・単元・難易度・復習・自由学習・章/学年進行は Kids Quest を正本とし、ManaEvo 都合で簡略化しない**
- バトル／捕獲／育成／進化は ManaEvo 専用として実装する
- キャラクター画像・正式名称は別検討。現在は `speciesId` + プレースホルダー表示で分離する
- 子どもの「もっと遊びたい」「捕まえたい」「進化させたい」が追加学習につながる設計にする
- 実装レビューの仕様基準は `design/` を優先する。ただし Kids Quest 由来の学習仕様を変更する場合は、先に仕様変更として明示して合意する

## 基本ループ（Kids Quest 基準）

1. 今日の**5つの教科タスク**を学習する
   - 国語・算数: 各5問
   - 通常教科: 各4問
   - 道徳: 2問（Kids Quest 側の該当日）
2. 5タスクをすべて完了すると、バトルチケット3枚 + ほしのわ3個
3. 今日の基本を終えた日だけ新規バトル開始可能
4. 18タイプ・4技・交代を使ってバトル
5. HPを減らして4種類の「わ」で捕獲（最大3投）
6. もっと学びたい場合は**自由勉強**。好きな教科を選べるが、チケットは出ない
7. もっとバトルしたい場合は**追加チャレンジ3問**。3問中2問正解でチケット+1
8. MASTERで上位の「わ」を獲得し、捕獲・XP・通常進化・図鑑を進める

### 重要: 「わからない」を消さない

Kids Quest と同じく、問題には `🤔 わからない（こたえを みる）` を残す。

- 適当に選択肢を押す代わりに「わからない」を選べる
- 記録上は誤答として扱う
- 正解と解説を見せる
- その後にもう一度解く／復習へつなげる

「わからない」を正直に選ぶことを不利な抜け道にせず、学習行動として扱う。

## 学習ゲート

- 間違えたこと自体は罰しない
- 正解するまで学習項目を完了扱いにしない
- 誤答・「わからない」の場合は **解説確認 → 再回答**
- 今日の5教科タスクが未完了なら、前日からチケットを持ち越していても新規バトル不可
- 自由勉強はチケット獲得の抜け道にしない
- 追加チケットは3問中2問の追加チャレンジで獲得する

## チケット

- 基本学習: 5教科タスクをすべて完了して3枚
- 追加チャレンジ: 3問中2問正解で1枚
- 自由勉強: 0枚
- 獲得日を含む7日間保持
- 期限の近いものから消費
- 新規バトル開始時に1枚reserveして `activeBattle` に出所を保存
- **敗北・明示的に「やめる/逃げる」: 1枚返却**
- **勝利・捕獲成功: 消費確定**
- reload / Safari終了 / crash: 同じ `activeBattle` を再開し追加消費しない

## 「わ」

| 種類 | 初期性能 |
|---|---:|
| ほしのわ | ×1.00 |
| ぎんのわ | ×1.20 |
| きんのわ | ×1.50 |
| にじのわ | 100% |

非にじは92%上限。倍率はconfig化してプレイテストで調整可能にしています。「わ」は期限なしです。

## Kids Quest 学習資産

- `src/kids-quest-study/` に Kids Quest `main` の学習専用スナップショットを保持
- `SOURCE_COMMIT.txt` にコピー元SHAを保存
- SRS・難易度・learningUnitsをMana Evo実行系へ接続
- snapshot内のrelative importは解決済み
- ゲーム固有の battle / monsters / weapons はコピーしない
- 全学年・全教材UIをMana Evoのroutingへ完全接続する作業は継続中
- `src/study/kidsQuestMission.js` は、ManaEvo の現行縦切り画面で Kids Quest の「5タスク / 4〜5問 / 自由勉強チケットなし / 追加3問2正解」のルールを固定する回帰ガード

### 2026-08-23 回帰の経緯

初期縦切り実装で、Kids Quest の学習フローをそのまま接続せず、ManaEvo 側に「全科目合計5問」「自由学習1問正解でチケット+1」という簡略版を新設してしまった。その後 Kids Quest の学習ソースをコピーしたが、実画面は簡略版の `src/study` を使い続けたため、コピー済みの正しい仕様が反映されなかった。

この回帰を防ぐため、以後は **Kids Quest の学習仕様を正本**とし、ゲーム側の都合だけで学習回数・自由勉強報酬・「わからない」導線を変更しない。

## バトル・育成

- 18タイプ、手持ち3体、場に1体、各4技、交代可能
- 敵はステージ固定レベル帯
- 個体別HP保持。交代全回復なし
- 捕獲失敗は敵ターン
- 通常進化は `level / stone / held_item_level` を実マスタで実装
- 石・もちものをステージ報酬から獲得し、詳細UIから進化できる縦切りを実装

## 特殊形態

採用:

- **ギガシンカ**
- **キョダイバースト**

不採用:

- **スター覚醒**

ギガキー/種族ギガコア/バーストのしるしは永久・非消費の所有権として扱います。ギガシンカの基本取得ループ（最終進化→専用チャレンジ/ボス→勝利→種族コア→永久解放）と、キョダイバーストの1戦1回・3ターン・ギガとの同時使用不可は既決です。対象種族一覧と個別チャレンジ割当は別マスタ作業です。
