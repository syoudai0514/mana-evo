# Mana Evo（マナエボ）

Kids Quest の学習基盤を活かしつつ、ゲーム部分を新設計として独立実装するリポジトリです。

## 絶対方針

- `syoudai0514/kids-quest` 本体は変更しない
- 学習系（問題・単元・難易度・復習・自由学習・章/学年進行）は Mana Evo に移植して再利用する
- バトル／捕獲／育成／進化は Mana Evo 専用として実装する
- キャラクター画像は当面プレースホルダー。`monsterId` 単位で後から差し替える
- 学習がゲーム時間を生む設計にする

## 基本ループ

1. 今日の基本学習を5問クリア
2. バトルチケット3枚を獲得
3. バトル・捕獲・育成を遊ぶ
4. チケットがなくなったら自由学習
5. 自由学習は正解1問ごとにチケット+1（上限なし）
6. 単元マスター／むずかしいマスター／章の試練／学年MASTERで進化素材を解放

## 学習設計

- 基本学習: 5教科を偏らせず出題
- 自由学習: おすすめ / 苦手克服 / 得意を伸ばす / 好きな科目 / チャレンジ
- 同一科目を続けるほど難易度を少し上げる
- 単元マスター条件: 4回以上挑戦・初回正解3回以上・別日2日以上・複数形式
- 復習: Kids Quest のライトナー式SRSを移植
- 先取り: 科目ごとに独立して上の学年へ進める

## 進化報酬

- 通常進化: レベル中心
- スター覚醒: Lv.25 + 指定単元MASTER + 「むずかしい」MASTER + スターのかけら
- ギガ進化: 最終進化 + Lv.40 + ギガストーン + 対応章「むずかしい」完全MASTER
- キョダイバースト: 科目/学年MASTER + バーストコア + 対応モンスター

## 開発

```bash
npm install
npm run dev
npm test
npm run build
```

現段階ではキャラクターはプレースホルダー表示です。正式キャラクターデザイン確定後、学習ロジックを触らず画像だけ差し替えられる構造にします。
