# Mana Evo（マナエボ）

Kids Quest の学習基盤を活かしつつ、ゲーム部分を新設計として独立実装するリポジトリです。

## 絶対方針

- `syoudai0514/kids-quest` 本体は変更しない
- 学習系（問題・単元・難易度・復習・自由学習・章/学年進行）は Mana Evo に移植して再利用する
- バトル／捕獲／育成／進化は Mana Evo 専用として実装する
- キャラクター画像・正式名称は別検討。現在は `speciesId` + プレースホルダー表示で分離する
- 子どもの「もっと遊びたい」「捕まえたい」「進化させたい」が追加学習につながる設計にする

## 基本ループ

1. 今日の基本学習を5問クリア
2. バトルチケット3枚を獲得
3. マップからステージへ出発
4. 18タイプ・4技・交代を使ってバトル
5. HPを減らして「わ」で4段階捕獲
6. チケットがなくなったら自由学習
7. 自由学習は正解1問ごとにチケット+1（上限なし）
8. 捕獲・XP・レベルアップ・通常進化・図鑑を進める

## Kids Quest 学習資産

- `src/kids-quest-study/` に Kids Quest `main` の学習専用スナップショットを保持
- `SOURCE_COMMIT.txt` にコピー元SHAを保存
- SRSと自動難易度調整は、Mana Evo実行系がコピー済みKids Questコードを直接利用
- ゲーム固有の battle / monsters / weapons / missions はコピーしない

## 学習設計

- 基本学習: 5教科を偏らせず出題
- 自由学習: おすすめ / 苦手克服 / 得意を伸ばす / 好きな科目 / チャレンジ
- 正答が続くと Kids Quest の難易度エンジンで段階的に難しくする
- 単元マスター条件: 4回以上挑戦・初回正解3回以上・別日2日以上・複数形式
- 復習: Kids Quest のライトナー式SRS
- 先取り: 科目ごとに独立して上の学年へ進める前提

## バトル・育成

- 18タイプを維持
- 手持ちは3体、場に出るのは1体、各モンスター4技、交代可能
- 技選択前に `◎ ばつぐん / ○ ふつう / △ いまひとつ / × きかない` を表示
- 敵はステージ固定レベル帯。プレイヤーへ完全追従させず、育成した強さを実感できるようにする
- 捕獲は敵HP50%以下から。「わ」を1個消費し、4段階の★判定で成功
- 通常進化までの残りレベルを常時表示

## 特殊変身

最終ゲームレビューに合わせ、正式名称は以下のみを採用します。

- **ギガシンカ**
- **キョダイバースト**

`スター覚醒` は現行の正式ゲームレビューにはないため実装から除外しています。

ギガキー／ギガコアの名称は採用済みですが、取得条件・消費有無・組み合わせ方の最終ルールが確定していない部分は推測実装せず、通常進化・バトル・捕獲と独立したロック状態にしています。

## 開発

```bash
npm install
npm run dev
npm test
npm run build
```

正式キャラクター確定後は、`speciesId` ごとの画像・名前・説明を差し替えます。学習進捗、バトルロジック、セーブ形式を変更せず差し替えられる構造です。
